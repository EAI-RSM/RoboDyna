Basic tasks

catch_marbles_trapdoors — Catch Marbles Trapdoors

basic

Target marble fell through the matching-color trapdoor into the box (below the trapdoor floor).

Requires

  • Target released through the matching-color door
  • Target is inside the box and below the original trapdoor floor level

Fails if

  • Opening the matching door under the marble alone is not enough if it never drops
  • Wrong-door / miss

Source: envs/catch_marbles_trapdoors.py → check_success()

catch_ramp_ball — Catch Ramp Ball

basic

Red target ball rests in the catch vessel (cup); distractor must not be in the vessel.

Requires

  • Target ball in vessel
  • If distractor enabled: distractor not in vessel

Fails if

  • Target missed cup
  • Distractor caught

Source: envs/catch_ramp_ball.py → check_success()

catch_cuboid — Catch Cuboid

basic

Required cuboid(s) are picked up / held.

Requires

  • Default: the (single) cuboid is held
  • Opt 1 (catch_two_cuboids): both cuboids held and catches ≥ 2

Fails if

  • Missed pop-up window
  • Only one of two caught in Opt 1

Source: envs/catch_cuboid.py → check_success()

catch_shelf_marble — Catch Shelf Marble

basic

Marble episode resolved as caught (in the bowl).

Requires

  • _marble_state == resolved and _marble_result == caught

Fails if

  • Missed / not caught

Source: envs/catch_shelf_marble.py → check_success()

catch_valley_ball — Catch Valley Ball

basic

Red ball is in the box past the red line; no arm–ball contact; distractor not in box.

Requires

  • Ball released
  • Target in box
  • Box past red success line
  • No arm–ball contact
  • Distractor not in box (when present)

Fails if

  • Ball not in box
  • Box not past line
  • Arm touched ball
  • Distractor in box

Source: envs/catch_valley_ball.py → check_success()

stop_valley_ball — Stop Valley Ball

basic

Red ball hits the bat head in mid-air before the table; bat still held off the table.

Requires

  • Ball released
  • Valid panel/head hit before table contact
  • Bat/panel still above min air clearance
  • No arm–ball contact
  • Distractor did not hit panel (when present)

Fails if

  • Table before hit
  • Missed panel
  • Panel resting on table
  • Distractor hit panel

Source: envs/stop_valley_ball.py → check_success()
