Dynamic manipulation that cannot wait.

RoboDyna is a dual-arm benchmark for scenes that keep changing: objects fall and move, belts run, food cooks, timers advance, and distractors appear while the robot acts.

View repository Explore all tasks Quick start

What RoboDyna measures

The benchmark tests perception, prediction, timing, and closed-loop control under changing physical state—not static pick-and-place geometry alone.

Time-evolving scenes

Targets move, belts run, timers advance, and object state changes at every physics step.

104 Base conditions

23 Base tasks each include Default, Opt 1, Opt 2, and Opt 1+2 conditions that systematically alter the challenge.

Comparable evaluation

Human experiments and policy evaluation share fixed, expert-validated seeds for each task and condition.

Task gallery

Browse every Base and Household task. Base cards let you switch among the four published condition demos; Household cards have one representative expert demo.

GIFs load only as you browse.

Get started

git clone https://github.com/EAI-RSM/RoboDyna.git
cd RoboDyna
bash script/install_robodyna.sh
conda activate robodyna
bash script/_download_assets.sh

# Explore the benchmark
python interactive/robodyna_gui.py
One instruction and one protocol.
Every task uses a single canonical language instruction. Human experiments and policy evaluation use the same fixed task-and-condition seeds.
