Task parameter randomization

Dedicated on/off toggles for per-episode parameter noise added to 14 tasks. Values below match demo_dynamic.yml (household also in demo_kitchens.yml). Set the toggle to false to freeze the nominal scalar.

Convention. Symmetric jitter uses U(base × (1 − j), base × (1 + j)). One-sided cases are noted explicitly. Related page: task_randomization.html (broader “what is effective” catalog).
